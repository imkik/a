# 🧮 Algebra Helper (9th Grade)

A simple Python program that automatically calculates the discriminant and finds the roots of a quadratic equation. It helps to quickly double-check your math homework!

## 🚀 How to Run:
1. Make sure you have Python 3.x installed.
2. Download the `script.py` file.
3. Run the script using PyCharm or your terminal.

## 💻 Tech Stack:
* Python 3.14
* Built-in `math` library
